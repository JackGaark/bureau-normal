# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Static single-page portfolio site for Bureau Normal, an architecture studio. Built from a Figma design. All user-facing copy, `alt` text and ARIA labels are in French (`<html lang="fr">`); keep new text in French.

## Commands

pnpm and Vite. There is no linter or test suite.

```
pnpm run dev      # Vite dev server on http://localhost:8000
pnpm run build    # build src/ into dist/
pnpm run preview  # serve the built dist/
```

Source is in `src/`. `dist/` is build output, but it is committed because deployment is static hosting of `dist` (configured in `.openai/hosting.json`). Never edit `dist/` by hand; run the build and commit the result alongside source changes.

## Architecture

Three hand-written files: `src/index.html`, `src/style.css`, `src/app.js`. No runtime dependencies and no framework; Vite only serves and bundles. `vite.config.js` sets `root` to `src`, outputs to `../dist`, and uses `base: './'` so the built site works from any path. `style.css` is formatted one declaration per line, grouped under section comments (tokens and resets, header, Survol, Index, Accueil and Bureau, mobile, reduced motion); add new rules to the matching section. The JS is densely written; match that style rather than reformatting, so diffs stay small.

**Hash routing.** `index.html` holds six `<section>`s directly under `<main>`: `#accueil` (the landing page and default route: studio statement and emblem; the Figma frame has no footer), `#diaporama` (full-screen slideshow, reached from the landing scroll and from index rows and Survol tiles; it has no nav link), `#survol` (thumbnail grid), `#index` (project list), `#projet` (one project's images, opened from index rows; its hash carries the entry index as `#projet/3`, parsed by `route()` as `page/arg`) and `#bureau` (the studio page). `#accueil` keeps the `.bureau` class for its styling; `#bureau` uses `.office`. `route()` in `app.js` reads `location.hash`, toggles the `hidden` attribute on each section, sets `aria-current` on the nav link, stops the slideshow (then restarts it if the page is `#diaporama`) and updates `document.title`. Header visibility lives in `head()`, which both `route()` and `show()` call: the `<header>` is hidden on `#accueil`, because the Figma landing frame has none. On `#diaporama` `head()` adds the `over` class: the Figma "TOP NAV" frame over the slides shows the wordmark and emblem in plain off-white (#E6E6E6 at 90%, done with a brightness filter on the #BAB8B6 logo), so the difference blend is turned off there and the inset is 20 px instead of 22. A project with `light:true` (the white axonometric, slide 4) makes `sync()` add `dark` to the header, which turns the marks #333 so they stay visible on a white image. A project with `menu:true` (slide 6) makes `sync()` open the header menu automatically while that slide is showing, so the Index, Survol and Bureau links appear without pressing the emblem; every other slide closes it again. The nav links are hidden by default on every page: the `.mark` emblem button toggles the `open` class on the `<header>` through `menu()`, which also keeps `aria-expanded` in sync; `route()` and the Escape key close it. The exceptions are `#index`, `#survol`, `#projet` and `#bureau`, where `head()` adds the `always` class to the `<header>`: the links are permanently visible and the emblem button is hidden, as in the Figma index and overview frames. Scrolling to the bottom of `#accueil` waits 0.7 s (cancelled if the visitor has scrolled back up by then), adds the `leaving` class (a 1.2 s opacity fade) and then redirects to `#diaporama`; the inner 1.2 s timeout in the scroll listener in `app.js` and the transition on `#accueil` in `style.css` must stay equal. Every section also fades in over 0.8 s when it becomes visible (the `enter` keyframes on `main > section`), so page switches are a fade out followed by a fade in. Adding a page means adding a section, a nav link, and the id to the allow-list inside `route()`.

**Data.** Two arrays sit at the top of `app.js`. `projects` drives the slideshow images (`slide-1.png` to `slide-6.png`, the owner's 1440×1024 exports; the older `stairs.png`, `facade.png`, `residence.png`, `maison.png` and `brick.png` remain for the Survol tiles and index previews), which are created in JS into `.slides`. `entries` drives the index rows in `.project-list`: each entry has `name`, `type`, `status`, `start`, `end`, `slide` (the index in `projects` whose image the index row previews) and `slides` (the list of `projects` indexes the `#projet` page steps through; placeholder: all six). `entries` is currently the Figma placeholder list, 33 copies of "475 Grande-Allée, Qc / Résidentiel / Complété / 2021 à 2025" all pointing at slide 0 (the Figma list image is byte-identical to `stairs.png`); replace it with real data. Things coupled to it that must be updated by hand when it changes:

- The slide counter total is hardcoded as `' / 06'` in `sync()`, and the initial caption and counter are hardcoded in `index.html`.

**Landing layout.** `#accueil` follows the Figma frame "HP LAND HERE | DESKTOP" (1440 px wide). Values in `style.css` are that frame's measurements expressed as proportions: 70 px padding all round (4.86% at the sides), a 68 px / 72 px headline as `4.72vw`, and the `brand.svg` emblem-and-wordmark (the frame's "ICON AND LOGO" group) starting at 36.14% of the frame height, i.e. 110.14vw, or one full screen down, whichever is greater (the `.intro` wrapper's `min-height`), and ending 70 px above the bottom; that makes the page about 4375 px tall at 1440 px wide against the frame's 4390. The headline copy is the studio's French text, not the frame's lorem ipsum. The design's typeface is Greed VF-TRIAL (a variable font, used at its Condensed Regular instance). It is not in the repo: an `@font-face` in the `<head>` of `index.html` (kept there rather than in `style.css` so the page-relative URL survives the `./` base even while the file is missing) expects `src/public/assets/fonts/GreedVF-TRIAL.woff2` (or `.ttf`); `:root` lists it first with `font-stretch: condensed` and `font-weight: 400`, and falls back to the Arial Narrow stack until the file is dropped in.

**Index page.** `#index` follows the Figma frame "INDEX | DESKTOP" (1440 px wide); its interaction is a port of `IndexList.svelte` from `bahnbahn-svelte`. An 8-column grid holds the column titles (Projet, Type, Status, Dates, as written in the design) and the `<ol class="project-list">` on columns 4 to 8, with an empty `.index-anchor` (520/390) on columns 1 to 3. The `.index-cols` template `344fr 168fr 168fr 168fr` reproduces the frame's x positions (548, 900, 1076, 1252), which also line up with the header links; titles sit at 93 px, the first project name at 141 px and rows are 27 px apart (19 px line, 6 px above, 1 px below, 1 px border). Rows are dimmed to 50%; `hover(i)` marks one row `active` (full color, underline) and `place()` positions the fixed `.index-preview` image over the anchor column, 3 px below the top of the project name, flipping up when it would pass the bottom of the viewport. As in the design, the first row is active when the page opens, and the last hovered row stays active. Clicking a row opens `#projet/<row>`. The page ends with `.index-logo` (the exported `index-emblem.svg` inside an `.emblem` wrapper with the two eye SVGs, and `index-wordmark.svg`, 25.6% and 70.6% of the content width, pushed to the bottom with `margin-top:auto`; the section's `min-height` is `max(100svh, 156.25vw)`, which makes the page exactly 2250 px tall at 1440 px wide, the Figma frame height) and a footer whose email, Instagram and year sit on list columns 2 to 4. Under the 700 px breakpoint there is no hover preview: tapping a row toggles `expanded` on its `<li>`, showing the image inline (that image is the link to `#projet/<row>`), and the `.expand-all` button toggles every row. The year is written into every `.year` element.

**Survol page.** `#survol` follows the Figma frame "OVERVIEW | DESKTOP" (1440 px wide): an 8-column grid of square tiles (`.tiles`, 8 px gap, starting at 144 px; 4 columns on mobile), then the same `.index-logo` and footer as the index page, here with the emblem absolutely positioned. On both pages the two eye SVGs sit over the emblem in percentages (`.emblem .eye`) and blink: the `blink` keyframes keep them open for 3 s and closed for 3 s (a 6 s cycle) (Figma frames 2861:513 and 2869:806 are the emblem without and with eyes); the blink also plays with reduced motion on, by the owner's choice. `min-height: max(100svh, 180.35vw)` makes the page 2597 px tall at 1440 px wide, the frame height. The 56 tiles are built in `app.js` from the `thumbs` array (8 images; `slide` is the slideshow image a tile opens, `y` an `object-position` crop taken from the design) using two strings that transcribe the Figma placeholder layout: `tiles` (one thumb index per tile, row by row) and `flips` (`1` for the tiles the design mirrors horizontally). Every tile links to `#diaporama`. Projects are runs of consecutive tiles: `runs` lists how many tiles each project owns in grid order (placeholder: eleven runs, the Figma "OVERVIEW Grid" frame only marks the first five tiles as one project) and the run index is the project's row in `entries`, whose `name` the label shows. Hovering or focusing a tile calls `light(k)`, which adds `lit` to every tile of that project: an overlay (`.tiles a::after`, the Figma "Overview Thumbnail" rectangle: #E6E6E6 at 90% under 80% layer opacity, flattened to `.72`) with the `.tile-label` (17 px, rgba(51,51,51,.8), centered) showing the project name and the tile's position in its run (`01/05`). The four `survol-*.jpg` thumbnails are Figma exports downscaled to 1000 px (the originals are 4 to 7 MB each); `stairs.png`, `facade.png` and `residence.png` are reused because the exports were byte-identical.

**Projet page.** `#projet` follows the Figma frame "PROJET | DESKTOP" (1440 × 1024; `min-height: max(100svh, 71.111vw)`). `project(n,f)` in `app.js` shows frame `f` of entry `n`: the image sits on columns 2 to 7 of the 8-column grid (1047 × 744 at 1440 px, `object-fit: cover` on a `rgba(51,51,51,.2)` placeholder), the stage is split down the middle into two full-height buttons; hovering (or focusing) a half reveals its 21 × 12 arrow (`arrow-prev.svg`, `arrow-next.svg`) at the frame's position (previous at 92 px, 83% down; next 92 px from the right, 45% down), always shown on touch devices, and clicking the half steps through the entry's `slides`, wrapping; arrow keys do the same while the page is visible. The 14 px details row (counter `01/06`, name, `start à end` right-aligned to the image edge) sits on columns 2, 3 to 4 and 5 to 7, and the uppercase "Projet précédent / Projet suivant" links at the bottom go to the neighbouring entries, wrapping.

**Bureau page.** `#bureau` follows the Figma frame "BUREAU | DESKTOP" (1440 × 1575; `min-height: max(100svh, 109.375vw)`). `.office-grid` is the same 8-column, 8 px-gap grid as the other pages (columns at 20, 196, 372, 548, 724, 900, 1076, 1252 px): the 42 px / 54 px statement on columns 1 to 5, the portrait placeholder (344 × 486, `rgba(51,51,51,.2)`, text "Photo de vous :)" until a photo replaces it) on columns 7 to 8, the 17 px body copy on columns 1 to 3 in a second row 15 px under the portrait (the first row is `33.75vw`, the portrait's height), and the 14 px contact line (address, phone, email, Instagram) on columns 1 to 4. The copy is the Figma lorem ipsum; replace it. `.office-foot` is pushed to the bottom: the wordmark on columns 1 to 3 (520 px) with the same email / Instagram / year `.index-cols` footer as the other pages, bottom-aligned with it.

**Slideshow behavior.** The carousel uses the same technique as `Carousel.svelte` in the sibling `bahnbahn-svelte` project: `.slides` is a native horizontal scroll container (a column-flow grid of 100%-wide slides on a single 100%-tall row, so the images' percentage height resolves instead of overflowing the viewport, each image filling the viewport with a centered `object-fit: cover` crop, with `scroll-snap-type: x mandatory`, `scroll-behavior: smooth` and a hidden scrollbar), and the animation is the browser's smooth scroll, not a CSS transition. `show(i)` wraps around, scrolls to `i * clientWidth` and calls `sync()`, which updates caption, counter and `aria-hidden`; an `IntersectionObserver` (threshold 0.5) calls `sync()` too, so native touch or trackpad scrolling keeps the caption right. Going from the last slide to the first rewinds through all of them, as in the Svelte project. A hidden section cannot scroll, so `route()` calls `show(current,false)` (instant) when `#diaporama` opens. Autoplay (`start()`) begins automatically whenever `#diaporama` opens, advances every 2 s, loops, and stops on route change and when the tab is hidden; the Lecture/Pause button toggles `start()` and `stop()`. `step(d)` stops autoplay first. Input: prev/next buttons, arrow keys only while `#diaporama` is visible and focus is not on a button or link, native horizontal touch scrolling, and the mouse wheel or trackpad over `#diaporama` (one slide per gesture, throttled to 0.8 s, autoplay timer restarted; adding wheel deltas to `scrollLeft` as the Svelte project does gets cancelled by scroll snapping here).

**Styling.** Design tokens are `--paper`, `--ink` and `--pad` on `:root`. The fixed header uses `mix-blend-mode:difference` with paper-colored content so it stays legible over both photos and the light pages; keep header content single-color. The header follows the Figma "TOP NAV" frame: a four-column grid (`879fr 177fr 175fr 169fr`, the frame's x positions at 1440 px) holding the logo and the Index, Survol and Bureau links (`nav` is `display:contents`), plus the `.mark` emblem button, absolutely positioned top right, which opens the menu: the links sit at opacity 0, shifted 40 px toward the emblem, and slide out staggered from right to left when the header has `open`; on mobile it becomes a flex row. One mobile breakpoint at `max-width:700px`, plus a `prefers-reduced-motion` rule that disables transitions on everything except `.slides`, `#accueil` and `nav a`: the slideshow autoplays and animates, the landing fade plays, and the emblem eyes blink, even with reduced motion on, by the owner's choice. Images live in `src/public/assets/` and are copied to `dist/assets/` unprocessed. They must stay in `public/` because `app.js` builds their URLs from strings (`'assets/'+p.image`), which Vite cannot trace or hash.
